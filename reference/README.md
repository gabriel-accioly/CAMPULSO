# Referências executáveis dos contratos

Os diretórios poc001-domain e poc002-domain guardam cópias literais dos módulos backup e model nas implementações históricas. A suíte de compatibilidade testa o arquivo canônico contra esses leitores. A variável CAMPULSO_POC001 pode apontar para a POC-001 original em leitura. Os módulos de referência não entram na entrada pública de produção do Vite.
