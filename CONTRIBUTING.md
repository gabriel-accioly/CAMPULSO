# Contribuir

Use dados fictícios para demonstrar um problema. Informe versão, navegador, dispositivo, rota, passos e resultado esperado. Para falhas de segurança, siga [SECURITY.md](SECURITY.md). Antes de propor uma dependência ou ampliar o escopo, explique a necessidade, o impacto no uso offline e a licença.

Trabalhe em um branch de escopo pequeno. Rode `npm run typecheck`, `npm test`, `npm run build` e os testes específicos do fluxo. Importação, migração, edição concorrente e atualização do Service Worker exigem verificar a preservação das onze coleções. Para interface, inclua navegação por teclado, foco, nomes acessíveis e comportamento em tela estreita. Descreva quais cenários você conseguiu executar.

Envie somente material que você possa oferecer sob a licença do projeto. Preserve autoria e avisos de terceiros. O mantenedor revê escopo, compatibilidade, privacidade e acessibilidade antes da incorporação. O canal para contribuições será o repositório oficial depois da abertura autorizada.
